You are working on an EXISTING functional project called CIRCUIT — AI-Powered Unused Logistics Capacity Exchange.

Your task is to redesign and elevate the existing frontend UI/UX into a highly distinctive, professional logistics operations platform.

This is NOT a request to rebuild the application from scratch.

Your first priority is to understand the existing project, its routes, components, state, data, matching logic, and user flows.

Then redesign the interface while preserving the functionality.
